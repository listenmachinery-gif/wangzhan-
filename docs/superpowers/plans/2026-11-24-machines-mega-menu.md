# Machines Mega Menu 实施计划

**Spec:** `docs/superpowers/specs/2026-11-24-machines-mega-menu-design.md`

## Task 1：导航配置与真实目录解析

- 扩展导航快照 Schema，加入向后兼容的 Machines 配置。
- 增加默认八大系列与菜单设置。
- 新增纯函数解析器，把配置与真实已发布目录合并并过滤失效引用。
- 用单元测试覆盖默认顺序、覆盖值、排序、隐藏和过滤行为。

## Task 2：桌面与移动端导航

- 用共享视图模型替换旧级联菜单。
- 实现桌面全宽 Mega Menu、键盘与延时交互、遮罩和资源入口。
- 实现移动端全屏三级钻取、返回、真实产品缩略图和固定 CTA。
- 增加组件交互测试。

## Task 3：后台 Machines 管理

- 扩展导航管理页，注入真实目录数据。
- 增加中文 Machines 配置面板、分类/产品排序、显示开关、覆盖字段和桌面/移动预览。
- 保持现有保存草稿、发布、权限和版本回滚接口。
- 增加后台编辑及保存载荷测试。

## Task 4：验证与交付

- 运行相关单元测试、全部单元测试、TypeScript、ESLint 和生产构建。
- 用 Playwright 或本地浏览器检查关键宽度与交互，修复发现的问题。
- 审查差异、提交功能分支并更新 Draft PR；不合并或生产部署。

## Review Focus

- 旧发布快照是否仍可解析。
- 未发布产品是否可能因管理配置泄露到前台。
- 桌面和移动菜单是否使用同一已发布快照。
- 菜单关闭、焦点恢复、滚动锁定和小屏布局是否可靠。
