# 产品总页具体产品卡片编辑规范

## 目标

在现有“产品总页”后台编辑器内，为 Banner 下方每个已发布具体产品增加独立的标题、摘要、图片及图片替代文字编辑入口。

## 行为约束

- 产品列表、分类归属、排序、详情页链接仍以已发布产品资料为准。
- 编辑内容只覆盖 `/products` 产品总页卡片显示，不修改产品详情页。
- 未设置覆盖时自动显示产品资料中的当前标题、摘要和首图。
- 每张卡片可一键恢复为产品资料默认值。
- 图片支持直接填写站内路径或从媒体资源库选择。
- 摘要在前台卡片中可见；标题与摘要保留后台输入的换行。
- 图片必须有可编辑 Alt 文本，前台图片使用该文本。
- 旧的已发布产品总页内容无需迁移即可继续解析。
- 以后再次执行产品总页发布脚本时不得清除人工设置的卡片覆盖。

## 验收

- 后台产品总页编辑器按八个分类显示对应的具体产品卡片编辑项。
- 保存、重复修改、刷新后数据持久化。
- 前台切换分类后显示对应覆盖内容且产品链接不变。
- 无覆盖的产品继续自动继承真实产品资料。
- 单元测试、类型检查、静态检查和生产构建通过。
