# ZYRON Machines Mega Menu 设计说明

## 目标

在不改变现有产品路由、产品数据和导航发布机制的前提下，把 `PRODUCT_DIRECTORY` 升级为可配置的桌面全宽 Mega Menu 与移动端三级导航，并在现有导航管理页中提供中文化配置、预览、草稿、发布和回滚能力。

## 架构

- Machines 配置存入现有 `NavigationDocument` JSON 快照，继续复用 `NavigationVersion`、权限、审计和发布流程，不新增 Prisma 表。
- 前台以已发布导航快照为配置源，以已发布产品分类和产品为内容源；配置中不存在、停用或未发布的产品不会显示。
- 旧导航快照没有 Machines 配置时使用内置八大系列默认配置，保证向后兼容。
- 桌面端和移动端共用一个 `MachinesMenuView`，避免两个入口内容不一致。

## 交互与视觉

- 桌面端为 Header 下方全宽浮层，最大内容宽度 1440px：左侧系列导航，右侧 3/4 列产品卡片，底部为产品中心、技术支持和询价入口。
- 鼠标、键盘、Escape、点击外部均可操作；打开和关闭有短延时，减少误触；背景遮罩不引起页面位移。
- 移动端使用全屏抽屉和“主菜单 → Machines 系列 → 产品”钻取结构，提供返回按钮、系列总览和固定询价入口。
- 管理端分为主导航、Machines 菜单、页脚与版本记录。Machines 支持启用、模式、系列名称/说明/顺序/默认项/显示、产品覆盖信息和桌面/移动设置。

## 数据安全

- 仅保存产品/分类稳定 slug 引用和展示覆盖值，不复制或删除业务数据。
- 所有链接仍由真实分类和产品 slug 生成。
- 本次只提交功能分支和预览验证，不合并 main、不发布生产。
