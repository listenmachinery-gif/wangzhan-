# About ZYRON 内容与文字控制设计

## 目标

在保留现有八个 About ZYRON CMS 模块和真实询盘功能的前提下，按用户提供的参考图调整第 1、2、4、7 模块，并修复后台“单独文字样式已保存但前台无效”以及文字不能换行的问题。

## 方案

- 沿用现有 PageBuilder、组件注册表和页面文档，不新建第二套编辑器。
- 第 1、2 模块通过 CMS 默认内容中的显式换行和等高网格实现指定行数与统一间距。
- 第 4 模块使用参考图的标题、数据和宽幅图片比例，图片采用站内永久资源。
- 第 7 模块把代码绘制地图改为 CMS 图片字段，并接入现有媒体资源选择器。
- 单独文字样式继续使用现有 `textStyles` 数据结构；为 About 自定义组件补齐 `data-page-text` 绑定，确保生成的范围样式能命中真实文字节点。
- 后台普通文字输入改为多行编辑，渲染层统一保留换行符。

## 约束

- 第 3、5、6、8 模块内容和布局不做结构调整。
- 不修改 URL、SEO 路由、询盘 API、数据库结构或其他页面内容。
- 媒体资源保存永久站内地址，并同步可用的图片替代文字。
- 完成类型检查、Lint、测试、生产构建、预览验收后再合并发布，并通过 CMS 发布最新 About 文档。
