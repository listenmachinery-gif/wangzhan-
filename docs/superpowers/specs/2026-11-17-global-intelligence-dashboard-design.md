# ZYRON 全球业务数据中心设计方案

## 目标与使用者

将现有 `/admin` 的“数据总览”原地升级为面向 ZYRON 管理员的企业级商业智能大屏，使管理者在一个页面内回答五个核心问题：网站现在是否有人访问、哪些市场与渠道有效、哪些产品最受关注、询盘是否及时跟进、数据源是否可信。

页面继续受现有 Session 与 RBAC 保护。没有 `analytics.read.summary` 权限的角色保留原有轻量运营概览，不暴露访客、来源或聚合数据。

## 仓库审计

### 已具备

- Next.js 15 App Router、React 19、TypeScript、Tailwind CSS。
- Prisma 7 + PostgreSQL；生产构建已执行 `prisma generate`。
- 后台 Session、角色权限、审计日志以及管理 API 鉴权。
- 第一方匿名访客、会话、页面浏览、事件、产品关联、聊天与询盘关联。
- GA4 Data API 与 Google Search Console 报表适配器，支持连接、未配置、超时、无权限和无数据状态。
- 第一方日报汇总、实时访客轮询、CSV 导出、询盘列表和产品库。
- Vitest、Playwright 和受测试数据库保护的集成测试。

### 直接复用

- `/api/admin/analytics/first-party/overview`：当前在线、5 分钟活跃、今日访客、会话、浏览量。
- `/api/admin/analytics/reports`：趋势、国家、来源、设备、产品、第一方漏斗。
- `/api/admin/analytics/overview`：GA4 和 Search Console 聚合报表及连接状态。
- `/api/admin/inquiries`：授权范围内的最新询盘与跟进状态。
- `/api/admin/analytics/reports/export`：受 `analytics.export` 权限保护的 CSV。

### 本阶段不新增

- 不新增 Prisma 模型或迁移。
- 不重复安装 GA4/GTM，不改变公开网站埋点。
- 不将 GA4/Search Console 聚合数据拼接到个人访客。
- 不生成演示数据，也不通过 IP 推断客户身份。

### 后续可扩展

- GA4 Realtime API 的官方 30 分钟聚合视图。
- 支持跨国家、设备、来源的多维交叉聚合。
- 用户级大屏布局偏好与自定义组件顺序。
- Web Vitals、机器人诊断与数据同步审计的独立持久化。

## 方案比较

### 方案 A：复用现有 API 的组合式大屏（采用）

在 `/admin` 使用独立的客户端大屏组件，并行读取现有第一方、Google 和 CRM 接口。优点是最小改动、数据口径稳定、无需迁移、可逐个数据源降级；代价是国家和设备筛选只能作用于已有维度模块，不能伪装成多维归因。

### 方案 B：新增单一 Dashboard 聚合 API

服务端将所有数据一次性聚合。首屏请求数量更少，但会重复已有服务边界，放大单点失败，并需要设计更复杂的权限缓存。本阶段不采用。

### 方案 C：新建独立 `/admin/command-center`

可以完全隔离大屏，但会违背“原地升级数据总览”，并形成两个管理入口。本阶段不采用。

## 信息架构

### 日常管理模式

保留现有侧边导航和顶部工具条。`/admin` 内容区使用深色大屏画布并可垂直滚动：

1. 标题、更新时间、数据健康摘要、日期范围、国家、设备、刷新、导出、自动刷新、全屏。
2. 核心 KPI：当前在线、今日访客、今日会话、今日浏览、所选周期询盘、询盘转化率、GA4 活跃用户、Search Console 点击。
3. 多序列访问趋势与实时访客指挥区。
4. 世界流量地图与国家排名、渠道来源分布。
5. 转化漏斗、热门产品、热门页面、搜索关键词。
6. 最新询盘跟进和数据源健康状态。

### 全屏指挥中心模式

对大屏根节点调用浏览器 Fullscreen API。进入后现有侧边栏与后台顶栏自然退出视口，仅保留大屏工具栏；退出后回到原位置。全屏模式不改变路由和数据权限。

### 响应式

- `>= 1536px`：12 栏高密度大屏。
- `1024–1535px`：双栏主图表和信息面板。
- `< 1024px`：单栏重排；表格局部横向滚动，不产生页面级横向溢出。
- `< 640px`：KPI 双列、筛选横向滚动、图表保持最小可读高度。

## 组件与数据边界

- `GlobalIntelligenceDashboard`：请求编排、筛选状态、刷新、自动刷新、全屏。
- `DashboardToolbar`：全局控制和数据状态摘要。
- `DashboardKpiGrid`：真实值、比较值、来源和不可用原因。
- `MultiSeriesTrendChart`：第一方访客/会话/浏览/询盘趋势及无数据状态。
- `WorldTrafficMap`：基于标准世界地理数据的国家着色、选择和等价排名表。
- `ChannelDistribution`：来源占比与明细。
- `ConversionFunnel`：仅展示可验证的第一方访客、聊天、显式关联客户和询盘提交。
- `ProductRanking`、`SearchPerformance`、`InquiryPulse`、`DataSourceHealth`：各自只消费对应真实接口。

大屏不直接读取数据库或第三方凭据。客户端只访问现有受保护 API；每个数据源独立失败和重试，不让单个来源导致整页白屏。

## 数据口径

- “当前在线”“5 分钟活跃”和“今日”指标来自第一方匿名分析，不与 GA4 合并。
- GA4 活跃用户、会话、浏览量、互动率和关键事件保留官方定义。
- Search Console 点击、曝光、CTR、平均排名保留其完整自然日和延迟说明。
- 第一方询盘转化率 = 所选周期 `INQUIRY_SUBMIT / visitors`；访客为 0 时显示 `--`，不显示 `NaN` 或无穷大。
- 产品排行以产品 ID 聚合并显示数据库产品名。
- 世界地图使用第一方国家维度；Google 国家数据仅在独立 Google 模块中展示。
- 日期预设沿用当前真实支持的近 7/28/90 天。今日数据单独在实时 KPI 中展示，避免把未完成自然日与完整历史日混算。

## 交互与可访问性

- 日期切换更新 URL，并重新读取对应数据。
- 国家和设备筛选只影响具备该维度的数据模块，并在工具提示中说明范围。
- 刷新按钮立即重新请求；自动刷新默认开启，60 秒执行一次，可暂停。
- 导出继续使用现有权限接口；没有权限时不显示导出。
- 图表提供可读标题、隐藏数据表或等价可见表格；颜色不是唯一状态表达。
- 支持键盘焦点、减少动态效果、错误重试、加载骨架和空数据说明。

## 安全与性能

- 保留 `analytics.read.summary`、`analytics.export` 和 CRM 读取权限。
- API 响应继续使用私有、不可共享缓存策略。
- 各接口并行请求，单独 AbortController；日期变化取消旧请求。
- 地图组件动态加载，其他图表使用轻量 SVG，避免新增第二套图表框架。
- 不记录密钥、请求令牌或完整 IP；不在大屏显示匿名访客的推断身份。

## 验收

- `/admin` 原路由展示新大屏，其他后台路由和公开网站不变。
- 十个核心板块均有真实数据、明确空态或未连接状态。
- 筛选、刷新、导出、自动刷新、全屏和下钻链接真实可用。
- 桌面 1920×1080、1440×900、1366×768 和移动端无页面横向溢出。
- 单元、集成、E2E、类型检查、Lint、生产构建和 Preview 全部通过后请求生产授权。
