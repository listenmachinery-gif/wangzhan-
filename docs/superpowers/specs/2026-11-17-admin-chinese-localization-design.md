# ZYRON CMS 管理后台统一中文显示设计

## 意图

让外贸业务人员在管理后台看到的系统标签、状态、来源、设备和国家/地区名称使用中文，重点解决访客分析和 CRM 中国家代码、流量来源及枚举状态直接显示英文的问题。

## 目标

- ISO 国家/地区代码显示为中文名称，例如 `US` 显示为“美国”、`DE` 显示为“德国”。
- 访客来源、媒介、设备、在线状态和事件属性统一中文显示。
- 产品、分类、页面、Banner、媒体、SEO、用户角色、聊天和 CRM 中的系统枚举统一中文显示。
- 筛选项、表格、详情抽屉和 CSV 导出使用相同的中文语义。
- 保留 Google、WhatsApp、Facebook、LinkedIn、SEO、CRM、URL、IP 等通用品牌和专业缩写。

## 非目标

- 不翻译客户填写的姓名、公司、需求、邮件和产品内容。
- 不修改数据库中的 ISO 代码、枚举值或 UTM 原始值。
- 不修改 API 字段、现有 URL 或前台外贸官网内容。
- 本阶段不引入中英文后台切换。

## 方案比较

1. **逐页替换**：改动快，但重复映射多，容易漏掉新页面。
2. **统一中文显示层（已选）**：建立可共用的显示函数和标签字典，所有后台模块共用，数据存储和 API 保持不变。
3. **完整多语言框架**：可扩展多语言，但超出当前只需中文后台的范围。

## 实施设计

### 1. 统一显示工具

在管理后台专用的本地化模块中提供：

- `formatCountryName`：使用 `Intl.DisplayNames("zh-CN")` 将合法 ISO 代码显示为中文国家/地区名，无效值安全回退为原值或“未知”。
- `formatTrafficSource` / `formatTrafficMedium`：将 `direct`、`organic`、`referral`、`none` 等标准值转为中文，搜索引擎和广告平台保留品牌名。
- `formatDeviceType`：将 `desktop`、`mobile`、`tablet` 转为“桌面端”、“移动端”、“平板”。
- 系统枚举字典：覆盖发布状态、聊天状态、角色、媒体用途、客户来源和客户等级。

### 2. 界面覆盖

- 数据分析：访客列表、访客时间线、报表、来源、国家/地区和设备。
- CRM：询盘列表、询盘详情、客户列表和客户详情中的国家与来源。
- 在线聊天：访客国家、设备和会话状态。
- 内容管理：产品、分类、页面、Banner、SEO 和媒体资源的枚举值。
- 系统管理：用户角色与账号状态。

### 3. 筛选和导出

- 筛选仍提交原始代码，界面选项显示中文。
- 访客 CSV 导出中的列头、国家、设备、来源和状态改为中文；原始 UTM 参数不被覆写。
- 需要精确核对时，中文国家名可以辅助显示 ISO 代码，但中文名是主要信息。

## 异常与回退

- 空值显示“未知”或“—”，依当前界面语义而定。
- 未收录的 UTM 来源保留原始值，避免丢失营销追踪信息。
- 非 ISO 国家值保留客户原文，不猜测或错译。

## 验收标准

- 管理后台不再直接显示可翻译的英文枚举值。
- 访客列表、访客时间线和聊天上下文中的 `US` 统一显示为“美国”。
- 查询参数、API 响应、数据库值和现有 URL 不变。
- 新增单元测试覆盖国家、来源、媒介、设备和未知值回退。
- 访客分析与后台关键 E2E 测试通过，类型检查、Lint 和生产构建通过。
