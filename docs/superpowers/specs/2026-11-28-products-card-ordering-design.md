# 产品总页产品卡片排序与增减设计

## 目标

在现有“产品总页”后台的具体产品卡片区域增加排序、移除和重新添加能力，同时保持所有卡片指向真实已发布产品。

## 方案

- 采用每个固定分类独立的卡片布局配置，保存“人工排序的产品 ID”和“已隐藏产品 ID”。
- 未配置时完全沿用数据库顺序，保证旧数据兼容。
- 排序后，未来新发布且未被隐藏的产品自动追加在末尾。
- “移除”仅从产品总页该分类隐藏，不删除产品、不修改产品详情页。
- “添加”只能从当前真实分类内已发布但已移除的产品中选择，避免无效链接和错误分类。
- 后台提供上移、下移、移除、重新添加及恢复默认排序按钮。
- 文案、图片和 Alt 覆盖继续按产品 ID 生效，移动或隐藏不会丢失已有编辑内容。

## 验收

- 前台按后台配置顺序展示，并过滤已移除产品。
- 新发布产品在已有人工排序之后自动出现。
- 后台操作后保存、重复修改和刷新均可持久化。
- 恢复默认后回到数据库排序并显示该分类全部已发布产品。
- 旧页面文档无需迁移即可正常解析。
